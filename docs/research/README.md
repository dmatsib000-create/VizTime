# Research

Background research behind what TimeFall (first VizTime) claims about each platform. Each report is a dated snapshot: some of its recommendations have since been built, and [device-tests.md](../device-tests.md) records what real devices then showed. Where they disagree, the device tests win.

| Report | Question |
|---|---|
| [2026-11-09-casting-to-a-tv.md](2026-11-09-casting-to-a-tv.md) | Can TimeFall cast to a TV the way YouTube does, from the web page and both apps? What Google Cast, AirPlay and mirroring each allow, and why TV view was built instead of casting. |
| [2026-11-07-timefall-native-apps.md](2026-11-07-timefall-native-apps.md) | How does VizTime become the TimeFall iPhone and Android apps for a few friends, what does it cost each year, what do the apps fix, and what stays impossible? Every decision, with prices and limits checked that day. |
| [platform-assumptions.md](platform-assumptions.md) | Do the README's claims about Windows, iPhone, Android and hosting hold up? Which are wrong, and which device tests would settle the rest? |
| [iphone-home-screen-pip.md](iphone-home-screen-pip.md) | Why does Float fail in the iPhone Home Screen app when it works in a Safari tab, and is there a way round it? |

The [notes/](notes/) folder holds the working notes each report was written from, with every source linked: one file per platform or question.
