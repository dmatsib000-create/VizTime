# Research

Background research behind what VizTime claims about each platform. Each report is a snapshot from 1 November 2026: some of its recommendations have since been built, and [device-tests.md](../device-tests.md) records what real devices then showed. Where they disagree, the device tests win.

| Report | Question |
|---|---|
| [platform-assumptions.md](platform-assumptions.md) | Do the README's claims about Windows, iPhone, Android and hosting hold up? Which are wrong, and which device tests would settle the rest? |
| [iphone-home-screen-pip.md](iphone-home-screen-pip.md) | Why does Float fail in the iPhone Home Screen app when it works in a Safari tab, and is there a way round it? |

The [notes/](notes/) folder holds the working notes each report was written from, with every source linked: one file per platform or question.
